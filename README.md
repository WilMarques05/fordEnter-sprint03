# Ford < Enter > - Sprint 03: HTML 5 / CSS

Este repositório foi desenvolvido como parte da **Sprint 03** do curso de Front-End do programa **Ford < Enter >**, uma iniciativa realizada em parceria entre a **Ford** e o **SENAI/CIMATEC**.

## 🎯 Objetivo do Projeto
O foco principal desta etapa foi o treinamento prático de **desenvolvimento de layouts responsivos**. O objetivo foi consolidar na prática tudo o que foi passado durante a sprint, tags semânticas com **HTML5** e design responsivo com **CSS**, simulando processos reais de desenvolvimento.

> **Nota:** O projeto contido neste repositório foi criado exclusivamente para fins didáticos, não representando um projeto de software final ou funcional.

## 🛠️ Tecnologias e Ferramentas Exploradas
* **Git:** Controle de versão local (init, add, commit, branch, checkout, merge).
* **GitHub:** Hospedagem de repositório remoto e gerenciamento de commits.
* **CSS:** Estilização da página.
* **HTML5:** Estrutura básica utilizada para gerar conteúdo versionável.

## 📝 O que foi praticado
Durante esta sprint, foram exercitados conceitos fundamentais como:

1. **HTML5 Semântico:** Substituição de tags genéricas por elementos estruturais nativos (`<main>`, `<nav>`, `<section>`, `<figure>`) para garantir a melhor leitura do documento, acessibilidade e SEO.

2. **Layouts Modernos com Flexbox e CSS Grid:** Uso combinado e estratégico dos dois modelos de posicionamento. CSS Grid para estruturas bidimensionais complexas (como o Footer distribuído em 3 colunas) e Flexbox para alinhamentos verticais e horizontais fluidos.

3. **Responsividade Mobile-First Avançada:** Construção de layout focado inicialmente em telas pequenas de 320px com a criação de um breakpoint inteligente em **665px** projetado para adaptar a experiência perfeitamente ao **modo paisagem (landscape)** de dispositivos móveis e desktops.

4. **Resolução de Conflitos e Organização de Código (Git & GitHub):** Fluxo profissional de desenvolvimento baseado em múltiplas ramificações (*branches*), mantendo o histórico de evolução de cada página preservado no GitHub (`feat/pagina-home`, `feat/pagina-lancamento` e `feat/pagina-contato`) e aplicando o padrão global de *Conventional Commits*.

5. **Otimização de Assets e UI/UX:** Manipulação, tratamento e substituição de imagens para versões com fundos transparentes, além do controle preciso de nitidez, preenchimento e escala (`object-fit: contain`) para evitar distorções visuais em monitores de grande resolução.
